| `cad-render.jpg` | Rendered view of the assembly (from CAD repo) |

## Adding images

To add a photo:

1. Rename it on your computer to one of the names above (or a clear descriptive name).
2. In GitHub, navigate into `images/` and click **Add file → Upload files**.
3. Commit.

Then reference it in the root README's **Photos** section.
